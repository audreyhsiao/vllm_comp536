## Prefix Caching 詳細流程

```
請求到達
  │
  ├─► Prompt: "Hello, how are you?"
  │
  ▼
計算 Block Hashes
  │
  ├─► Block 0: hash("Hello, how are")
  ├─► Block 1: hash("Hello, how are you?")
  │
  ▼
查找 Cache
  │
  ├─► Block 0 的 hash 在 cache 中？
  │   ├─► 是 → 重用 Block 0 (HIT!)
  │   └─► 否 → 分配新 Block 0，計算後加入 cache
  │
  ├─► Block 1 的 hash 在 cache 中？
  │   ├─► 是 → 重用 Block 1 (HIT!)
  │   └─► 否 → 分配新 Block 1，計算後加入 cache
  │
  ▼
統計結果
  │
  ├─► 如果 Block 0 和 Block 1 都 HIT
  │   └─► prefix_hit_ratio = 2/2 = 100%
  │
  ├─► 如果只有 Block 0 HIT
  │   └─► prefix_hit_ratio = 1/2 = 50%
  │
  └─► 如果都沒有 HIT
      └─► prefix_hit_ratio = 0/2 = 0%
```

## 關鍵指標收集流程

```
每個請求處理時：
  │
  ├─► 記錄 prompt 長度
  │   └─► total_prompt_tokens
  │
  ├─► 檢查 cache hit
  │   ├─► 如果 block 在 cache 中
  │   │   ├─► 記錄 hit_block_ids
  │   │   ├─► 計算 prefix_hit_tokens
  │   │   └─► 計算 prefix_hit_ratio
  │   │
  │   └─► 更新 block 統計
  │       ├─► hit_count++
  │       ├─► 計算 reuse_interval
  │       └─► 更新 last_accessed_time
  │
  └─► 聚合到全局統計
      └─► PrefixStatsCollector
```
